# ClinicalTriage Evidence Corpus

This directory contains metadata and controlled evidence used by ClinicalTriage.

## Evidence principles

Clinical recommendations must be grounded in identifiable sources.

Each source must have:
- unique source ID
- title
- organization
- source URL
- publication date when available
- version when available

## Source hierarchy

Preferred sources:
1. Official clinical guidelines
2. Government health agencies
3. Professional medical organizations
4. Peer-reviewed literature
5. Major academic medical institutions

## Versioning

Clinical evidence changes over time.
Every production evidence source should therefore record:
- publication date
- version
- retrieval date
- source URL

## Important

The evidence corpus must not contain real patient information.
Evidence retrieval supports clinical decision-making software.
It does not replace professional clinical judgment.
